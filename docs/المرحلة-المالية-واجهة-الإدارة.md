# واجهة الإدارة المالية — تحديث التصميم

تمت إضافة بوابة الإدارة المالية داخل لوحة المدير العام مع الالتزام بنظام التصميم الحالي للمشروع.

## مرجع التصميم الحالي
- RTL مفعل على مستوى التطبيق.
- خط Cairo هو الخط الأساسي.
- الألوان تعتمد على design tokens الحالية (`primary`, `card`, `muted`, `border`) بدلاً من نظام ألوان مستقل.
- البطاقات تستخدم النمط الحالي rounded-xl / border / shadow.
- الأزرار تستخدم مكوّن Button الموجود في المشروع.
- الشارات تستخدم Badge الحالي.

## الملفات
- `artifacts/pharma-pwa/src/pages/director/FinancialDashboardPage.tsx`: بوابة الإدارة المالية.
- `artifacts/pharma-pwa/src/App.tsx`: إضافة مسار `/director/financial`.
- `artifacts/pharma-pwa/src/layouts/DirectorLayout.tsx`: إضافة الإدارة المالية إلى تنقل المدير العام وعنوان الصفحة.

## مبدأ UX
الواجهة المالية لا تعرض أرقاماً مالية وهمية. في هذه المرحلة تعرض وحدات النظام وحالة النواة فقط، إلى أن تُربط مؤشرات الصفحة مباشرة باستعلامات وتقارير مالية موثوقة.

أي صفحات مالية لاحقة يجب أن تستخدم نفس مكوّنات التصميم الحالية، وألا تنشئ theme أو sidebar أو نظام ألوان منفصلاً.
