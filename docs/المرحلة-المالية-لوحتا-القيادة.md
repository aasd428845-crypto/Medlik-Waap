# المرحلة المالية — لوحتا القيادة (اللوحة المالية + لوحة التحكم التشغيلية)

## الفرع
`main` (تطوير مباشر على الفرع الحالي)

## الهدف
تنفيذ مهمة تصميم بلوحتين بنفس نمط MedLink الحديث (ألوان المشروع الحالية `primary/accent`، خط Cairo، RTL، بطاقات `director-panel`):

1. **اللوحة المالية** — `/director/financial/dashboard`
2. **لوحة التحكم التشغيلية** — تطوير لوحة القيادة الحالية `/director/dashboard`

> قاعدة صارمة: **لا توجد أي بيانات افتراضية أو وهمية** — كل الأرقام في اللوحتين تُقرأ مباشرة من قاعدة البيانات الفعلية (Supabase). عند تعذّر الاتصال تُعرض حالة خطأ واضحة بدلاً من أي أرقام مزيّفة.

## 1) اللوحة المالية — `FinancialDashboardPage.tsx`

**الملف:** `artifacts/pharma-pwa/src/pages/director/FinancialDashboardPage.tsx`
**المسار:** `/director/financial/dashboard`

### المكونات المبنية (حسب المواصفة)
- **شريط جانبي أيسر ثابت**: نفس هوية MedLink (موروث من `DirectorLayout`).
- **صف بطاقات KPI (4 بطاقات)**: كل بطاقة = أيقونة ملوّنة داخل خلفية دائرية فاتحة + رقم كبير Bold + نسبة تغيّر ملوّنة (▲ أخضر / ▼ أحمر) مقارنة بالفترة السابقة:
  - الإيرادات (30 يوم) — مقارنة بـ(30–60 يوم سابقة)
  - هامش الربح الإجمالي %
  - صافي التدفق النقدي
  - إجمالي الذمم المدينة
- **بطاقة بارزة "سعر الصرف الحي 💱"**: تدرّج لوني بلون Primary، تعرض `USD/YER` و`SAR/YER` بخط كبير، طابع زمني "آخر تحديث: قبل X دقيقة" (محسوب من `effective_date` الفعلي)، وسهم اتجاه (▲/▼) مقارنة بآخر سعر مسجل.
- **رسم بياني خطي كبير** (AreaChart من recharts): اتجاه الإيرادات لآخر 12 شهراً.
- **رسم بياني أعمدة جانبي** (BarChart أفقي): ربحية كل فرع مقارنة ببعضها.
- **قائمة "آخر الحركات المالية"** أسفل الصفحة: فاتورة صدرت، عمولة دُفعت، مصروف سُجّل، سند قبض — بدمج مصادر حقيقية.

### مصادر البيانات الحقيقية (كما نُفذت)
| المؤشر | المصدر الفعلي |
|---|---|
| الإيرادات (30 يوم) ونسبتها | `orders` (Invoiced/Delivered) — فترتان: آخر 30 يوم مقابل 30–60 |
| هامش الربح الإجمالي % | القيود المرحّلة `financial_journal_entries` → `financial_journal_lines` → `financial_accounts` (حسابات revenue/cogs خلال 30 يوماً) |
| صافي التدفق النقدي | `financial_cash_movements` + `financial_bank_movements` (وارد − صادر خلال 30 يوماً) |
| الذمم المدينة | `users.current_balance` (role = client) |
| سعر الصرف الحي | `financial_exchange_rates` (أحدث سعرين لكل زوج) |
| الإيرادات الشهرية (12 شهراً) | `orders` مجمّعة شهرياً |
| ربحية الفروع | View `financial_branch_profitability` (revenue − cogs − expenses) مع أسماء `branches` |
| آخر الحركات المالية | `invoices` + `payout_documents` + `financial_expenses` + `financial_receipts` (مرتبة بالتاريخ) |

## 5) كود قاعدة البيانات (بالترتيب)

التنفيذات الحالية تعتمد على جداول/Views موجودة في migrations المالية. لتشغيل البيانات الفعلية على بيئة Supabase، يجب تطبيق migrations **بالترتيب التالي** (SQL Editor):

1. `supabase/migrations/0006_financial_core.sql`
2. `supabase/migrations/0007_financial_setup_rls.sql`
3. `supabase/migrations/0008_financial_audit_immutability.sql`
4. `supabase/migrations/0009_financial_auto_posting.sql`
5. `supabase/migrations/0010_financial_simple_entries.sql`
6. `supabase/migrations/0011_financial_doctors_payouts.sql`

> يوجد مثبّت موحّد يلصق 0006→0011 بالترتيب تلقائياً مع `drop policy if exists`:
> `supabase/financial_installer.sql` — شغّله مرة واحدة في SQL Editor ثم جرّب استعلامات `supabase/queries.sql`.

**استعلامات اللوحتين (مرجعية):**
```sql
-- الإيرادات (آخر 30 يوم) مقابل (30–60)
select coalesce(sum(total_amount),0) as revenue_30d
from orders where status in ('Invoiced','Delivered')
  and created_at >= now() - interval '30 days';

-- هامش الربح الإجمالي (30 يوماً) من القيود المرحّلة
select
  coalesce(sum(case when a.account_type='revenue' then l.credit - l.debit else 0 end),0) as revenue,
  coalesce(sum(case when a.account_type='cogs' then l.debit - l.credit else 0 end),0) as cogs
from financial_journal_entries e
join financial_journal_lines l on l.journal_entry_id = e.id
join financial_accounts a on a.id = l.account_id
where e.status = 'posted' and e.entry_date >= now() - interval '30 days';

-- سعر الصرف الحي
select from_currency_code, to_currency_code, rate, effective_date
from financial_exchange_rates
where (from_currency_code, to_currency_code) in (('USD','YER'),('SAR','YER'))
order by effective_date desc limit 8;

-- ربحية الفروع
select * from financial_branch_profitability;

-- الذمم المدينة
select coalesce(sum(current_balance),0) from users where role = 'client';

-- المخزون الحرج
select count(*) as items, count(distinct branch_id) as branches
from warehouse_inventory where available_quantity < 10;
```
